## The two findings worth remembering
- **`sandbox="allow-scripts"` does NOT hide `window.webkit.messageHandlers` from the subframe.** The code-review verifier proved it with a standalone WKWebView harness (`scratchpad/wktest/main.swift`): the iframe's script delivered `{type:"change"}` with `isMainFrame=false`, which would have rewritten the open note as the user's own commit. Fix = `guard message.frameInfo.isMainFrame` in `WebEditorView.Coordinator`; the sandbox is defence in depth only. Fleet sweep: no other repo has a WKScriptMessageHandler.
- **Re-checking state after each await is not a fix when the callee is nonisolated.** `LiveSvodClient` is `@unchecked Sendable`, so `await client.writeFile` hops off the main actor and `vaulted()` reads `activeVault` AFTER the model's last check; the adversarial verifier reproduced vault A's content written into vault B. Fix = explicit `inVault:` variants of history/revision/writeFile/deleteFile on `SvodClient`, vault captured once. Verified: the default vault resolves by explicit id too (`VaultManager.resolve`), so `?vault=<default>` is safe.
